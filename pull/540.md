## Bug fix à inclure dans cette PR : recalcul des numéros après drag & drop

Quand on déplace un exercice/entraînement par drag & drop, **le numéro affiché** (dans le rond à gauche) reste figé à son ancienne valeur. Exemple : l'ancien « 2 » reste « 2 » même s'il est passé en première position.

### Fix à appliquer

Dans chaque fonction `dragend` (après réorganisation des éléments dans le DOM), **recalculer les numéros affichés** :

```javascript
// Recalculer les numéros visibles après drag
const items = list.querySelectorAll('.exercice-item');
items.forEach((item, index) => {
    const numero = item.querySelector('.exercice-numero');
    if (numero) numero.textContent = index + 1;
});
```

### Où l'appliquer

1. **`initSavoirFaireDragDrop()`** dans `js/admin-banques-exercices.js` — dans le `dragend` des exercices, juste après le `insertBefore`
2. **`initEntrainementsDragDrop()`** dans `js/admin-banques-exercices-connaissances.js` — même chose pour les entraînements de connaissances
3. **`initBanquesQuestionsDragDrop()`** dans `js/admin-banques-exercices-connaissances.js` — même chose pour les questions de connaissances (le numéro dans `.exercice-numero` ou équivalent)

Le fix doit s'appliquer **immédiatement dans le DOM** (pas besoin d'attendre la réponse API), pour que l'utilisateur voie les numéros se mettre à jour instantanément après le glisser-déposer.
